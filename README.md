# eds220-hwk4
Eaton and Palisades Fires False Color Imagery

# About
The purpose of this repo is to visualize fire scars from the Eaton and Palisades fires. Some brief data cleaning is followed by both true and false color imageries of the data. 

# Repo Structure
eds220hwk4
├── hwk4-task2-false-color-Clemencon.ipynb
├── data
└── README.md
The analysis for this project is done in hwk4-task2-false-color-Clemencon.ipynb.

# Data
All the data for this project is housed in the repo's data folder. 
This project uses one dataset of Landsat 8 data from the Microsoft Planetary Computer data catalog, as well as two Cal Fire datasets showing fire perimeters of the Palisades and Eaton fires from the LA County GIS Hub.
